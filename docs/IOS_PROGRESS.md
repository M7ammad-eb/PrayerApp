## Widget and language fixes

- User confirmed the installed original app works, but widget showed only the placeholder and Home reported unavailable App Group storage.
- Official AltStore Classic source reads requested capabilities from original Mach-O entitlements, appends the team ID to groups, and writes profile groups into `ALTAppGroups` for app and extensions. Both Salati executables now resolve that metadata first.
- isideload 0.4.6 instead provisions `group.<rewritten parent app ID>`; both executables derive the same parent ID as a fallback, followed by the original native group. FileManager still enforces actual signed access; no private API or entitlement bypass.
- A separate AltStore-ready package carries ad-hoc App Group request metadata in both binaries for AltStore provisioning. No Apple certificate/profile/account is used in CI; AltStore must sign with the user's Apple ID. The fully unsigned variant is separate and lacks embedded capability requests.
- Preferences now use private UserDefaults with migration from accessible old preferences. Language/location persistence is independent of widget group access.
- Language is the first section in Settings, always visible as English/العربية controls. UI tests change English to Arabic, reopen without resetting onboarding/preferences, and switch back to English.
- Background refresh follows the actual permitted identifier from the signed Info.plist. Snapshot loading/writing tries accessible authorized groups and preserves language when its schedule expires.
